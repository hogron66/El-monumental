El Monumental 1978 Scoreboard – v3

What changed in this version:
- Uses the supplied clean second reference photo as the only scoreboard background.
- All colored annotation dots and markers are absent.
- Home and away scores are smaller and match the visual height of the team names.
- The period digit is smaller and precisely centered inside its original cell.
- The match timer is smaller and fits completely inside the TIEMPO DE JUEGO display.
- Optimized for smartphone use, especially iPhone landscape mode.
- All interface text is in English.
- Uses the supplied LED_BOARD_REVERSED font for the lit scoreboard text.
- Text appears projected directly onto the scoreboard surface instead of inside black boxes.
- The editing dialog opens at the top of the screen so the on-screen keyboard does not cover the name areas.
- The app remains a landscape-only PWA.

Usage:
1. Upload the full folder to a static host such as Cloudflare Pages.
2. Open index.html on your phone.
3. Add to Home Screen for the best iPhone/Android experience.
4. Tap the top title or team names to edit text.
5. Tap the clock to set current or historical time.
6. Use the period and score buttons to adjust values.
7. Use the timer controls for the match clock.
